## Task B: parked cars (4K asset), smoother edges **without any polygon increase**
Make the 4K car look smooth instead of faceted using **no additional geometry**: smooth shading with edges split by angle (Blender's "Smooth by Angle"/auto smooth, e.g. about 30-40 degrees), weighted normals if useful, cleaning bad normals/shading artefacts on triangulated surfaces, and, if it helps, small vertex nudges that improve the outline **without adding or removing vertices/faces** (the creator accepts the silhouette staying low-poly). **Hard rule: the face and vertex count of the car must be identical before and after** (record both counts in the report). Show before/after stills. If the hero car (7K) also looks faceted, report it with a still and ask; do not change it unasked.

## Task C: the human (character asset), customised, low poly, system unchanged
Replace Oscar with the new base character **without breaking the character system**: keep the object names (`CHAR_Human`, `CHAR_Human_Mesh`, `CHAR_Human_Street`, `CHAR_Human_Street_Mesh`, phone parenting to the right-hand bone, etc.), the rig bone naming/mapping used for Oscar (Rigify names; if the base ships with no rig, or a different one, rig it with Rigify to the same names and pose conventions so `animate.py`, the seated pose and the street walk keep working; if it truly cannot match, document the exact mapping change), scale (about 1.75 m), pivots, and the seated front-passenger pose and standing/texting pose. **Add what the plain base is missing, keeping the polygon count low:**
